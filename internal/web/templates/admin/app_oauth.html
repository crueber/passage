Overrides the global lifetime for sessions created by this app's OAuth sign-in. Blank or 0 uses the global default.

Blank means any scope a client asks for is granted. When set, an authorization request may only ask for scopes from this list; anything else is refused with invalid_scope. Include openid to allow an id_token. Letters, digits, dot, underscore, colon and hyphen are allowed.

RFC 8707 resource indicators this client may request. Each entry is an absolute URI (for example https://api.example.com) and the access token audience becomes the granted one. Blank means resource indicators are not accepted.
