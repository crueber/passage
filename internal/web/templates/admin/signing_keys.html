Signing keys

RSA keys that sign OpenID Connect id_tokens. The newest active key signs; every active key is published in the JWKS.

{{csrfField .CSRFToken}}

How rotation works

Rotating adds a key and makes it current without retiring the old one. Keep the previous key active at least as long as the longest id_token lifetime (one hour) before retiring it. Retiring a key stops it being served and accepted; only retired keys can be deleted. Live sessions and refresh tokens are opaque and are never affected by a rotation.
