A short slug used in the sign-in URL (/login/oidc/<name>). Lowercase letters, digits, dash and underscore.

Text on the sign-in button. Empty uses the name.

An absolute https URL. Passage reads its /.well-known/openid-configuration and requires the document's issuer to match. The iss claim must match this value exactly, including a trailing slash.

Stored encrypted with the instance key. Register <server.base_url>/login/oidc/<name>/callback as the callback URL with the provider.

Must include openid. Leave it empty for openid, email and profile.

Without this, a sign-in only links to an existing Passage account with the same verified email address.
