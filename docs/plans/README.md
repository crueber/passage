# Plans

Design plans, explorations and wireframes live here. A plan is a proposal, not a
commitment: it records the problem, the options considered, and the open
questions to settle before implementation.

Wireframes and screenshots for a plan live under
`assets/<plan-number>-<slug>/` beside the markdown, so the plan stays portable.
